WeatherMap SPA

Project Overview

WeatherMap is a Single Page Application (SPA) that allows users to search for cities, view current weather information, explore an interactive map, save favorite cities, share weather details, and view a five-day forecast.

Features

- Search for cities and view current weather.
- Interactive map using Leaflet and OpenStreetMap.
- Display temperature, weather conditions, humidity, and wind speed.
- Save favorite cities using localStorage.
- Share weather information.
- View a five-day weather forecast.
- Loading and error states.

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Leaflet
- OpenStreetMap
- OpenWeatherMap API
- PHP for the optional AI assistant backend

How to Run

1. Install and start XAMPP.
2. Place the project folder inside "C:\xampp\htdocs".
3. Start Apache.
4. Open "http://localhost/WeatherMap/" in your browser.

Security Note

API secrets must be stored securely on the server and must not be committed to a public repository.
